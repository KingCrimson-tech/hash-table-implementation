# Hash table in C


A string-to-string hash table using open addressing, double hashing, tombstones,
and automatic resizing.

Implementational Learning:https://github.com/jamesroutley/write-a-hash-table

Build and launch the interactive tester:

```sh
make
./hash_table
```

Example session:

```text
ht> set language C
ok
ht> get language
C
ht> delete language
deleted (if present)
ht> get language
(not found)
ht> quit
```
